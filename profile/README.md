# Nyveth

**Independent software, thoughtfully built.**

Nyveth is an independent software company building open-source tools, engineering infrastructure, intelligent systems, and useful applications.

---

## What We Build

- **Developer Tools:** Purpose-built developer tooling, CLI utilities, and scaffolding systems.
- **Engineering Infrastructure:** Local-first search engines, caching layers, and cross-platform UI systems.
- **Intelligent Systems:** Agent handoff architectures, autonomous workflow engines, and context continuity.
- **Applications:** High-performance desktop, mobile, and browser software designed for daily utility.

---

## Featured Projects

- [**OpenSearch**](https://github.com/Ashish6298/opensearch) — A privacy-first, self-hostable web search engine built from scratch in TypeScript featuring custom inverted indexing and zero tracking. *(Built by Nyveth)*
- [**Structify**](https://github.com/Ashish6298/Structify) — Enterprise-grade project scaffolding platform and CLI to generate production-ready architectures. *(Built by Nyveth)*
- [**CONTINUUM**](https://github.com/Ashish6298/CONTINUUM) — AI work continuity and cross-model agent handoff system across frontier and local LLMs. *(Built by Nyveth)*
- **Developer Computation Cache** — High-throughput deterministic build and computation caching engine. *(Built by Nyveth)*
- [**RESONIX**](https://github.com/Ashish6298/RESONIX) — Lightweight, offline-first local audio player built with Flutter. *(Built by Nyveth)*

---

## Open Source Philosophy

We believe software is most resilient when built openly with clear boundaries, minimal dependencies, and direct utility. Individual projects under Nyveth retain their own unique identities, architectures, and communities while adhering to rigorous engineering standards.
