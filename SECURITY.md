# Security Policy

Nyveth takes the security of its software tools, applications, and infrastructure seriously.

---

## 1. Supported Versions

Security updates and patches are actively provided for the latest stable releases on default branches of active projects.

---

## 2. Reporting a Vulnerability

If you discover a security vulnerability in any Nyveth project:

- **Do NOT open a public GitHub issue.** Public issues disclose vulnerabilities before patches can be deployed.
- **Report Privately:** Use the GitHub Private Vulnerability Reporting feature directly on the affected repository (`Security` tab -> `Report a vulnerability`).
- Alternatively, if private vulnerability reporting is unavailable, reach out directly to the repository maintainer through verified GitHub contact channels.

---

## 3. Responsible Disclosure

Please allow maintainers a reasonable time frame to investigate, reproduce, and resolve reported vulnerabilities before any public coordination or release.
